Symbolic-first drafts

Local preparation before any model repair.

The conservative symbolic parser recognizes a limited set of clauses, attitudes, modifiers and roles. Unsupported constructions remain UM source spans with diagnostics rather than invented semantic roles. Both exporters emit the same public field names used by their dialect prompts. Complete accepted drafts skip repair; incomplete drafts enter repair with their diagnostics. A whole file is never split into worker cases.
