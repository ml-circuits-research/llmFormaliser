Two dialects, six workflows

One complete source file per task. Internal scoring anchors do not split model requests.

Each dialect has a baseline, a selective single-repair flow and a symbolic-first single-repair flow. All generation and repair phases include the identical canonical dialect text file. The shared judge prompt defines full-file equivalence and partial semantic coverage.

Enqueue all tasks, then flush once. Compatible LLM phases batch together; local code and branching operate on each task’s own state. A wave waits for the current cohort before assembling subsequent batches. Accepted candidates skip repair. Model context and output budgets are resolved from pworker configuration; the 384000 output-token reservation is a ceiling, not a required output length.

Markdown uses phase headings and compact field headings such as ### tier:small. Prompts include files through ${{lib/prompts/clause-sop.txt}}; only the final input argument varies. Local phases contain explicit imports and code.
