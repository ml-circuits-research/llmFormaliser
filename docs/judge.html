Success

Two yes entailments, two true preservation fields, no mismatches and an equivalent verdict are required. Invalid JSON, contradictory fields and uncertainty are not success. Every selected example remains in the denominator.

Data isolation

Each judge input is built by its own preceding local conversion. The model sees a batch envelope with separate IDs; pworker routes each judgment back to its originating task. Each finish phase validates and writes only that task’s result.

Questions use answer conditions and directives use compliance conditions, not asserted occurrence. Judgments are estimates, not logical proofs.
