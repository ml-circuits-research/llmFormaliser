Shared SOP Lang syntax

One declaration per line; shared notation does not erase differences between the two semantic models.

@eventId TYPE key=value key=value ...
NotationConvention
@idUnique declaration identifier.
$idReference to an existing declaration; forward references are allowed.
key=valueFields attach to the declared record. No bracket wrapper around the whole declaration.
[a,b]Ordered list value. The Event IR prototype also accepts comma lists.
@m1 MOD target=$e1 label=time value=nowA separate SOP line attaches a modifier; no inline objects.
"quoted value"Quote spaces and ambiguous strings. Numeric quantities may be bare or quoted.
E / EV / p / st / tShared entity/event, predicate, assertion-status and tense concepts.
subj / obj versus ag / thGrammatical participants are not automatically semantic agent/theme roles.
neg / MOD versus OP / root / scLocal CNL-E negation/modality differs from explicit Event IR operator chains.

Validation

Failed conversions expose an errors array with independent diagnostics, record IDs, fields and source line numbers where known. The repair phase receives every collected diagnostic once. Syntax recovery continues across independent lines and fields; structural checks run only after syntax and references are reliable, avoiding cascades from partial records. Validation does not silently repair the source or establish semantic equivalence.

The shared parser rejects duplicate IDs, repeated scalar fields, malformed values and unresolved explicit references. Event-SOP PS.exists is list-valued: repeated exists fields are collected without dropping targets, recorded in normalization metadata and rendered as separate existence presuppositions. Clause-SOP validates its grammatical schema. Event-SOP validates the native typed graph and preserves every supplied field in CNL, including annotations. OP, Q, QS and L are legal reference targets; numeric values remain literals. Spelling conventions produce warnings rather than semantic rejection. A single batch-ID wrapper can be extracted losslessly, with provenance; active formalizations reject inline objects. Historical replay can explicitly opt into the archived spelling normalizer, recording each edit. Numeric modifier values remain numbers and numeric lexical units such as 10000_euro remain strings. Invalid formalizations skip the model judge and proceed to finish with an explicit failure.

Original prototype adapters and regression fixtures remain in lib/vendor for reference; six workflow files share two canonical dialect prompts.
